Use this skill when the person asks whether anyone disagrees with a claim, or asks for counterpoints, critiques or other readings of it.

Follow the instructions Percolate's server gives when you connect; they name the current tools.

1. Read the `finding-counterpoints` guide with Percolate's guide tool (`get_research_guide` or `get_guide`, whichever the server lists) and follow it.
2. Read the claim and frame the question it answers before searching.
3. Check the person's own Library first, including work that rests on the same study.
4. For outside work, import only what you have actually read, using the `importing-a-story` skill.
5. Propose how the claims line up. Your labels are proposals; the person confirms them in Percolate.

Do not:
- Declare who is right.
- Invent a disagreement. If the work you found agrees, or answers a different question, say so.
- Judge a source you have not read.
