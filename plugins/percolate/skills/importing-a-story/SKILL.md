---
name: importing-a-story
description: Import an essay or article from a link into Percolate as a private draft that credits its author and does not copy its text. Use when the person gives a link and asks to import it.
---

Use this skill when the person shares a link and asks you to import, save or read it into Percolate.

Follow the instructions Percolate's server gives when you connect; they name the current tools.

1. Read the `importing-a-story` guide with Percolate's guide tool (`get_research_guide` or `get_guide`, whichever the server lists) and follow it.
2. Read the piece. Save a structured reading that credits the author and links back to the original, never the piece's text.
3. Pin the evidence each claim was read from, as the guide describes.
4. Save the draft following the `making-a-package` guide, and pass on what the result says to tell the person.

Do not:
- Copy or closely paraphrase the author's text.
- Import a page you could not read. Tell the person what failed instead.
- Publish the draft.
