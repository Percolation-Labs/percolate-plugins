---
name: making-a-package
description: Build or revise a Percolate research package that states its question, claims and sources so a reader can check the argument. Use before saving or revising any package.
---

Use this skill when the person asks you to save an argument, article or notes to Percolate, or to change a package they already have.

Follow the instructions Percolate's server gives when you connect; they name the current tools.

1. Check what you may do for this person; the guide tool returns it. If an action is theirs to take, tell them instead of trying.
2. Read the `making-a-package` guide with Percolate's guide tool (`get_research_guide` or `get_guide`, whichever the server lists) and follow it.
3. Read the `telling-the-person` guide before your first save in the chat, and pass on what each result says to tell the person.
4. To change an existing package, read it first and pass the revision you read, so a change made since is not overwritten.

Do not:
- Publish anything. Packages are private; publishing is a separate step the person asks for.
- Draw the question wider than the evidence supports.
- Retry a revision that failed because the package changed. Read it again and redo the change.
