---
name: checking-a-package
description: Explain what supports a Percolate research package and where it is weakest, using its sources, trust signals and comments. Use when the person asks whether a package holds up or what backs a claim.
---

Use this skill when the person asks what supports a package, whether its argument holds up, or what readers said about it.

Follow the instructions Percolate's server gives when you connect; they name the current tools.

1. Read the current guides with Percolate's guide tool (`get_research_guide` or `get_guide`, whichever the server lists), then find and read the package.
2. Look up what supports the package and what readers commented.
3. Report claim by claim: the sources behind it, which evidence is shared with other packages, and where support is thin or missing.
4. Offer a revision only if the person asks. Then use the `making-a-package` skill.

Do not:
- Change the package while checking it.
- Treat a listed or published package as endorsed. Listing is not review.
- Add support that is not in the package's sources.
